# fMRI_update：社会信息影响下的道德与食物判断更新

本仓库保存行为实验一与 fMRI 实验二的 MATLAB / Psychtoolbox 任务程序及配套材料。研究关注被试在获知不同身份、不同规模的信息来源后，如何更新对他人判断的估计。

本文依据研究者确认、两份实验指导语及最新上传的 `try_first.m`、`try_second.m` 编写。最新上传脚本是这两份程序的权威版本；文件名中的 `try` 不代表它们只是练习程序。仓库另有 `train_first.m`、`train_second.m`，本次未修改，也未核验其与正式程序的一致性。

## 真实任务与指导语中的情境

真实被试先完成行为实验一的初次估计与信心评分，再在磁共振扫描仪中完成实验二的二次估计。两份指导语把这些真实任务称为“第三阶段”的两个部分。

指导语中的“第一阶段”和“第二阶段”是研究者确认的欺骗情境，并非实际完成的数据收集阶段：

- 虚构的第一阶段：一名人类参与者甲对道德行为和食物作出评分。
- 虚构的第二阶段：10 名人类与 10 个 AI 分别独立估计甲的评分。
- 被试被告知，后续看到的外部估计是从上述评价者中抽取 1 个或 8 个所得的平均值；实际外部评分由程序受控生成，没有调用真实人类评分数据库或 AI 服务。

被试估计的对象是参与者甲，不是报告自己的道德态度或食物喜好。身份和规模是呈现给被试的实验操纵信息；不能据此声称程序实际运行了多个 AI、采集多人评分或计算了真实群体平均值。指导语中的准确性报酬说明也属于被试接收到的任务说明；实际奖励结算方式见 TODO。

## 实验设计

研究采用 2×2×2 自变量组合：

| 自变量 | 水平 | 含义 |
| --- | --- | --- |
| 信息来源身份 | 人类 / AI | 告知被试的外部评价者身份 |
| 信息来源规模 | 1 / 8 | 告知被试的外部评价者数量 |
| 判断领域 | 道德 / 食物 | 估计甲认为行为有多不道德，或有多不喜欢食物 |

共 8 种组合。新版程序均设置 16 个 Block、240 个试次；指导语规定每个 Block 15 个试次，道德和食物各 8 个 Block。二次估计中，同一 Block 的领域及来源身份、规模保持一致。初次估计程序只呈现领域提示，不能把其条件编号理解为此时已向被试呈现来源身份和规模。

程序使用条件编号 1～8 表示道德材料、9～16 表示食物材料，来源类别以条件编号对 4 取模编码（余数 0 记为 4）。来源编码 1～4 与“1 人类 / 8 人类 / 1 AI / 8 AI”的确切对应关系仍需核对实际提示图片，见 TODO。

## 行为实验一：初次估计与信心评分

入口：[try_first.m](核磁代码来咯/try_first.m)。

1. 呈现词语刺激 1.5 秒。
2. 被试估计甲对该行为的不道德程度或对该食物的不喜欢程度。
3. 被试报告对本次初次估计的信心。

估计与信心均采用 0～30 的整数评分。道德分数越高表示估计甲认为该行为越不道德；食物分数越高表示估计甲越不喜欢该食物；信心分数越高表示对本次估计越有把握。

两个评分环节的光标初始位置均随机生成。J 向左、K 向右、F 确认；新版代码未为这两个评分循环设置作答时限。程序记录评分、信心、反应时及首次移动时间等，每两个 Block 后提供休息。

程序将初次估计写入 `临时数据存放点/FTtryrating.xlsx`，供实验二读取，并将行为结果写入 `实验数据/first_trydata/`。

## fMRI 实验二：二次估计

入口：[try_second.m](核磁代码来咯/try_second.m)。

1. 读取实验一的初次估计，并回顾该值 2 秒。
2. 呈现来源提示及外部评分；等待时间读取 `try_AD_jitter.xlsx`。
3. 被试在看到初次估计和外部估计后，保留或调整自己的估计。

二次估计光标从本试次初次估计开始。按键 3 向左、4 向右、2 确认；不调整也需确认。作答时限为 8 秒，超时会显示提示并记录 `istimeout`。新版代码仍记录超时时的当前评分，因此分析时应结合超时标记处理，不能把所有已保存评分都视为有效确认反应。

程序开始及每两个 Block 后的继续环节调用触发等待函数，代码监听 S 键，并设 0.5 秒防重复间隔。该实现不能直接证明扫描仪协议或实际扫描 Run 划分。试次间抖动时间读取 `try_random_numbers.xlsx`。结果写入 `实验数据/second_trydata/`。

## AD_Rating 的受控生成

设同一试次的初次估计为 `x = FTtryrating(k)`。程序在以下整数区间中随机抽取外部评分：

- 较低方向：`[max(0, x - 9), max(0, x - 3)]`。
- 较高方向：`[min(30, x + 3), min(30, x + 9)]`。

生成目标是使外部评分比初始估计低或高 3～9 分；区间端点受 0～30 量表边界限制。接近边界时，实际差值可能小于 3，甚至为 0，例如 x=0 时较低区间为 [0,0]。不能表述为每个试次都严格满足绝对差值 3～9。

实验二读取次序表的配对偶数行来决定每个 Block 的方向配比：8 低 / 7 高或 7 低 / 8 高，再用 `randperm(15)` 打乱 Block 内的方向。输出 `ADPlus` 中，1 表示较低方向、2 表示较高方向。实际差值应从保存的评分计算，特别是边界试次。

身份与规模操纵不改变上述生成公式。外部评分不是甲的真实评分，也不是真实人类或 AI 评价者的平均值。

## 刺激随机化、suborder 与 Block 顺序

[preclassify.m](核磁代码来咯/preclassify.m) 对道德与食物刺激进行随机化，并写出 `临时数据存放点/实验材料表.xlsx`。道德材料占前 8 列，食物材料占后 8 列。它不读取 `suborder`，也不生成或读取“被试实验次序表”。

研究者确认的操作流程是：每位被试开始前运行一次 preclassify，准备该被试的材料安排，并核对其 16 个 Block 的真实呈现顺序。实际 Block 顺序由实验程序读取 `代码中用到的Excel文件/被试实验次序表.xlsx` 决定。

两份新版脚本都在启动信息框的第六项 `Subject Order` 中手动输入 `suborder`：

```matlab
suborder = str2double(subinfo{6});
wrapped_suborder = mod(suborder - 1, 30) + 1;
tryconditionList = tryblockorder(wrapped_suborder * 2 - 1, :);
```

`suborder` 随被试更新，例如第 17 位被试输入 17；它不是固定常量。注释中的 `% suborder=17;` 不会执行。两次实验应输入同一被试的正确次序号，不能用默认值 999 代替。代码按 30 个次序循环，第 31 位会读取与第 1 位相同的次序行；此循环的设计依据见 TODO。

奇数行提供 16 个 Block 的条件顺序；实验二还读取紧邻的偶数行作为高低方向配比。刺激随机化与 Block 次序选择是两个不同机制。

数据索引 `k = 15 * (条件编号 - 1) + Block内试次号` 按条件编号组织；实验二另用 `j = 15 * (呈现位置 - 1) + Block内试次号` 读取抖动时间。输出行号不是实际呈现顺序，应结合 `blockorder`（呈现位置）、`try_block`（条件编号）及 `picID` 解释数据。

## 运行准备与文件衔接

1. 准备 MATLAB、Psychtoolbox、指导语图片、来源图标、词语图片及所需 Excel 文件。
2. 检查并统一路径：上传的两份实验脚本使用 E 盘绝对路径，而当前 preclassify 使用 F 盘绝对路径；直接运行前需确保读写指向同一套材料。
3. 为当前被试运行一次 preclassify，核对材料表及其对应的次序表行。
4. 运行实验一，手动输入正确的被试信息与 suborder。
5. 核对实验一导出的初次估计及材料对应关系，再运行实验二，输入同一被试的 suborder。
6. 保存当前被试的材料安排及结果后，再准备下一位被试。

材料表和 `FTtryrating.xlsx` 使用固定临时文件名，后者由实验一覆盖写入。两次实验之间重新运行 preclassify 或混用其他被试的临时文件会破坏刺激与评分对应关系。当前代码未实现完整的自动被试绑定检查。

本次更新只新增 README 并以研究者上传的原文替换两份正式脚本；没有修复或重构脚本，没有修改材料、次序表、练习程序或实验原始数据，也没有运行会写入实验结果的任务程序。
